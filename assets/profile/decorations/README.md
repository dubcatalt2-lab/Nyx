# Avatar decorations

The user requested these 25 avatar decorations from https://chillz0ne.dev/movies and stated that the site owner authorized copying them (September 14, 2026). This directory contains avatar decorations; full-card effects are in ../effects. The reference site's shop and currency are not imported.

`catalog.json` records the source labels and visually reviewed display names, exact public asset sources and local filenames. Original PNG/APNG bytes are preserved, including animation (24 animated assets and one static asset). `*-still.png` files are separate representative animation-frame renditions for reduced-motion and Lag Reducer display. Nyx serves these assets locally, without runtime requests to the reference site or Discord. These assets are not claimed as original Nyx artwork.
