Start with one project

  1. Download and run the installer. Open Nook Agent from the Start Menu.
  2. In Nook web, sign in and create an account API key. Save it in the desktop app’s Permissions & account page.
  3. Choose a project folder and review the access level and expiration time.
  4. Choose a model and describe your task. File access and model use follow your approved scope and existing account allowance.

What this release does

Version 0.1 includes a bounded agent loop, project exploration and text edits, conflict-aware undo, approved PowerShell and Command Prompt execution, Windows UI Automation, individually approved UAC requests, local task history, local notes, and an optional system tray.

The Stop button cancels inference and ordinary command processes. Administrator processes may continue after cancellation. Commands run with your Windows permissions; they are not a project sandbox.

Account keys are encrypted with Windows DPAPI. Task history stays on your computer. Content used in a task is sent to Nook and the selected model provider. Web conversations remain available in the separate Nook web window.

Release notes & limits

This is the first Windows release. Browser automation, schedules, MCP integrations, multi-agent delegation, cloud task synchronization and macOS/Linux installers are not included yet. Model availability and account limits are enforced by Nook.

Updates are manual: return here and install a newer verified release. No automatic startup service is installed. Uninstall through Windows Settings → Apps; local history and recovery files are retained.

Check the SHA-256 shown beside your download with PowerShell: Get-FileHash .\Nook-Agent-0.1.0-windows-x64-setup.exe -Algorithm SHA256.
