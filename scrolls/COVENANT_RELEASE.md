# Covenant engine release

The browser engine is independently implemented; no removed engine source is bundled. All five browser bundles now use short mangled local identifiers and AST-verified string escaping, in addition to existing minification, internal-property mangling and source-map removal. Escaping is performed at build time and does not add an execution-time string decoder. Religious names apply to project-owned source modules; generated variable names stay short to limit download and parsing overhead.

Thirteen project-owned engine modules now use Covenant vocabulary for addresses, transport, cookies, frames, streams, session persistence, caching and server connections. Native browser APIs, protocol fields, saved cookie/session schemas, and stable worker URLs are preserved. Existing `/boot/start.js` registration has no `.sw.js` filename. The document wrapper uses chapel/vestry/nave containers without rearranging upstream page markup.

The server relay entry is `/api/communion`; `/api/relay` remains available for already-configured clients. Wispurr remains a real server dependency under its proper package name. Its internal worker requires random private credentials; the public entry validates origins. Private server paths are denied by the static boundary. WebSocket traffic and downloaded JavaScript remain inspectable, and a public repository still exposes its tracked source. Naming and obfuscation are not access control.

Removed AI-specific robots exclusions, AI user-agent rejection, and user-agent-dependent alternate pages. General private-path indexing exclusions and authenticated service controls remain. Tests of deleted legacy engines were removed; the current network/browser/relay suites cover the replacement implementation, and CI now checks relative imports and crawler/browser content parity.

Validation before release: network/unit and Chrome/Edge dynamic smoke suites pass; isolated cookies/storage, clicked sign-in popup, forged-host denial and localhost persistence pass. Both relay protocol versions pass on both routes; missing/foreign origins and private-worker credential failures are rejected. Source layout resolves 694 imports. Deployment and branding checks pass. The initial popup-only build failed its hash-bound review gate after six compiled files changed; all 24 unchanged contexts were reviewed again (three saved-decoration migration keys and one historical preference export denylist key per file). Full raw scans remain in release audit output.
