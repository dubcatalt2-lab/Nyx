# Page wording and direct startup

This release is prepared separately from the unfinished dependency naming cleanup, based on ad85289. It removes the first-run Welcome to Nyx markup and startup branch, preserving explicit Terms acceptance, the loading indicator, account access and saved preferences.

Home and address entry use “Find a topic or enter an address.” Reference Search becomes Reference Library; nearby lookup labels use L00KUP and recent entries use Recent topics. Project-authored tab wording in controls, settings, tooltips, app instructions and accessibility labels becomes page/pages. Native keyboard Tab, ARIA role contracts, internal selectors and saved-data keys remain compatible. This is not a claim that every internal tab identifier has been renamed.

Builds regenerate hosted and static publisher assets from source. Fresh, unfinished and completed setup profiles pass desktop/mobile startup, Terms acceptance, editable Home entry, Settings wording, reload and preserved preferences. Production advertising remains disabled and retired Ultraviolet/SJ v1 runtimes remain excluded. Independent sibling applications are not changed.
